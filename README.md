---

## 💭 Why This Repo Exists

I learn best by building. When I encounter a concept I want to understand deeply — or one that tripped me up in real code — I write a mini-project that isolates that concept. This repo is the living collection of those projects.

Each project:

- 🎯 Focuses on one specific concept or a small set of tightly related concepts
- 🔨 Has a deliberately broken state first, then fixes it
- 👀 Includes observable outputs (console logs, rendered values) so I can verify it works

## 📁 How Each Project Is Structured

Each project folder contains:

- README.md — project notes including key observations made during the project and any design principles observed
- src/ — the actual code
- package.json / .csproj — build configuration

The project README.md is the guide. The code is the implementation.

## 🚀 Running a Project

### React projects

```bash
cd frontend/react-js/<project-name>
npm install
npm run dev
```

### C# projects

```bash
cd backend/dotnet/<project-name>
dotnet run
```
